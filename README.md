# Claude Code Full Course for Data Analysts: course code and data

Companion repository for the YouTube course **"Claude Code Full Course for Data Analysts"** on **TheDataScientist | Renjith R**.

You go from a messy CSV export to clean, tested data, business analysis, charts, a one-command monthly Excel report, notebooks, a Google Sheets export, a read-only MCP server, a second dataset (support tickets and SLAs), an AI pull-request review and a memo fact-check.

> **All data here is synthetic.** "Chai & Chips Co." is a made-up online store. The orders, customers and tickets were generated by `make_data.py` and `tickets/make_tickets.py` (fixed random seeds). They contain no real people or companies.

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python src/profile_data.py        # what is wrong with the raw export
python src/clean.py               # raw 8481 -> clean 8152 rows
pytest -q                         # cleaning rules + Sheets export tests
python src/analysis.py            # KPIs, cohorts, category and city mix
python src/investigate_drop.py    # is the October drop real?
python src/charts.py              # charts into reports/
python src/report.py 2026-10      # monthly Excel report into reports/
```

The datasets are already included. To regenerate them from scratch, run `python make_data.py` and `python tickets/make_tickets.py`.

Claude Code itself needs a paid Claude plan or an Anthropic Console account; see https://docs.anthropic.com/en/docs/claude-code/overview. None of the code in this repository calls the Claude API.

### Google Sheets (optional)
`python src/sheets_export.py` always writes the CSV pack. To push to a real Sheet, set `GOOGLE_SHEETS_KEY_FILE` (path to your own service-account JSON) and `SHEET_ID`. Never commit that key file; `.gitignore` already blocks common key-file names.

### MCP server
```bash
python src/build_db.py                                    # data/orders.db
claude mcp add --transport stdio --scope project orders -- python src/mcp_orders.py
```
The server opens the database read-only, accepts only SELECT queries and caps results at 200 rows. Written for the `mcp` Python SDK 2.x.

### AI pull-request demo
```bash
bash pr_review/run_demo.sh        # uses `python` on PATH; set PY=/path/to/python to override
```
